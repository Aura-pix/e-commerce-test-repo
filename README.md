# E-commerce Test API

A small in-memory product API created to test documentation tooling. Product
data is cleared when the server restarts.

## Run locally

Requires Node.js 20 or later.

```sh
npm install
npm run build
npm start
```

The server listens on `http://localhost:3000` by default. Set `PORT` to choose
a different port.

See the [API documentation](docs/api.md) for endpoints, fields, and errors.
